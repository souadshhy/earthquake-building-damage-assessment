# Shared report

Each owner maintains their section in the matching folder. Keep actual methods, cited sources, results and limitations; do not invent results before training/evaluation. The coordinator combines reviewed sections for submission during week four.

Data/evaluation → `data/`; models/training → `models/`; backend/geography → `backend/`; frontend/integration → `frontend/`. Keep final large/generated documents outside Git unless the team deliberately chooses a versioned source-document workflow. Describe the agreed project scope and actual measured behavior.
